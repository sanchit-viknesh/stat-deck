# StatDeck

A two-player stat-comparison card game where each card is a sports player: pick a stat, highest (or lowest) number wins the round.

> **Unofficial fan project.** Not affiliated with or endorsed by any player, team, league or stadium. Non-commercial, built for learning and for sharing with friends.

**Status:** scaffold only — Angular app shell, no game logic yet.

## Running it

```bash
npm install
npm start        # http://localhost:4200
npm test         # unit tests
npm run build
```

## Data, art and licensing

- **Player stats** in `public/data/deck.cricket.json` are approximate sample data for illustration, not a verified live feed.
- **No photos, crests, logos or official branding** are used. Player photos are a silhouette placeholder; stadium backdrops are original stylised drawings.
- **Fonts** are open-licence (SIL OFL). Dependencies must use permissive licences.
- Review rules for contributors and Claude sessions live in `CLAUDE.md`.
